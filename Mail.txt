Tu trouveras ci-joint le dossier compressé contenant les données extraites du site https://books.toscrape.com/.

Le code que j’ai développé correspond bien aux trois étapes d’un pipeline ETL :

Extract : le script récupère automatiquement, depuis le code HTML des pages du site, les informations sur les livres (titres, catégories, prix, disponibilité, etc.).

Transform : ces données brutes sont nettoyées et converties dans des formats exploitables (par exemple conversion des prix en nombres, normalisation des champs texte, organisation par catégories).

Load : les données finales sont exportées dans des fichiers CSV structurés, qui peuvent ensuite être chargés dans une base de données interne ou un outil de visualisation pour suivre l’évolution des prix dans le temps.

En programmant l’exécution régulière de ce script (par exemple une fois par jour), nous pourrions établir un pipeline ETL efficace.
